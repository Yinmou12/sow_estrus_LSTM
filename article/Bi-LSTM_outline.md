## Overview

论文主线建议围绕一个清晰问题展开：传统母猪发情检测依赖人工查情和接触式监测，存在主观性、漏检、成本和生物安全风险；耳标耳温数据可以提供低成本、连续、非侵入式的生理信号，但发情相关的耳温变化幅度细微，且容易受到昼夜节律、个体差异和现场采集噪声干扰，导致发情与非发情窗口在特征空间中存在重叠。本文通过构建 48 h 耳温时序窗口，引入耳温变化率作为动态特征，并结合 Bi-LSTM 与 ADASYN + SMOTE + Tomek Links 三阶段采样流水线优化训练样本的局部结构和边界分布，从而提升发情识别的泛化能力。

#### 3.4 三阶段采样流水线与数据增强

**Purpose**：描述 ADASYN + SMOTE + Tomek Links 三阶段采样流水线，并强调仅用于训练集。

**Content**：
- 训练集预处理阶段引入采样增强，避免在验证集/测试集中合成样本造成评估偏差。
- 明确说明实验数据总体接近平衡，三阶段采样流水线的主要目的不是“纠正类别比例”，而是改善训练样本在特征空间中的覆盖连续性和分类边界质量。
- 第一阶段 ADASYN：围绕局部难分类样本进行自适应补充，强化模型对模糊区域的学习。
- 第二阶段 SMOTE：基于近邻插值扩展样本邻域，使时序特征空间覆盖更连续。
- 第三阶段 Tomek Links：清理类别交界处的异类近邻样本，减少边界噪声。
- 建议在正文中画出流程图：原始训练集 -> ADASYN 局部补充 -> SMOTE 邻域扩展 -> Tomek Links 边界清洗 -> 模型训练。

**Local evidence**：`code/cross_validation.py` 中 `run_5fold_cv_with_aug`；`code/analysis.py`；`Readme.md` 对消融实验文件的说明。

#### 3.5 Bi-LSTM 模型结构

**Purpose**：准确描述模型架构。

**Content**：
- 输入：`(batch_size, 48, 2)` 双变量时序矩阵。
- 编码器：4 层 Layer-wise Bi-LSTM，隐藏单元数建议以最终实验配置为准，当前训练配置为 64。
- 表征提取：取最后一层正向和反向 hidden state 拼接；当前配置 `use_cell_state=False`，不拼接 cell state。
- 分类器：Layer Normalization -> 全连接层（32 维，ReLU）-> Dropout -> Sigmoid 输出发情概率。
- 阈值：默认 0.5，可在结果或讨论中说明是否调优。

**Local evidence**：`code/lstm_model.py` 中 `EstrusLSTM`、`LayerWiseBiLSTM`；`code/sow_estrus_LSTM_train.py` 中 `__train_info` 与 `get_model`。
